- FastAPI backend with 200+ endpoints, fed by 36 scheduled scraping and ETL pipelines into Supabase Postgres

- [Intel API](https://www.plus234feed.com/intel) and an [MCP server](https://www.plus234feed.com/mcp) that give developers and AI assistants current Nigerian rates, markets and a ~177,000-article archive, with the source and date on every answer
